# UART

简单的 8 位 UART,带有硬件 RX/TX 移位寄存器和可编程的波特率分频系数。实现在 `src/main/scala/uart/Uart.scala`(顶层)、`UartTx.scala` 和 `UartRx.scala` 中。

## 寄存器映射

外设内部的寄存器偏移:

| 偏移 | 大小 | 寄存器   | 描述 |
|------|------|----------|-------------|
| 0x0  | 1    | data     | RX 数据(读)/ TX 数据(写) |
| 0x1  | 1    | status   | 状态标志 |
| 0x2  | 2    | divisor  | 波特率分频系数 |

任何字访问的第 0 字节选中数据寄存器(`addr(1,0)` 被忽略,但第 0 位在读操作时选择 RX),因此最自然的方式是按单个字节访问这些寄存器。

## 寄存器

### data (0x0)

- **读:** 返回接收到的字节。只有当存在字节时读操作才会被接受(并释放缓冲区);`valid` 状态位指示这一点。
- **写:** 将低字节(`wdata[7:0]`,由 `wmask[0]` 门控)装入 TX 缓冲区。只有当缓冲区为空时写操作才会被接受;`ready` 状态位指示这一点。

### status (0x1)

| 位 | 名称  | 描述 |
|-----|-------|-------------|
| 0   | ready | TX 缓冲区可以接收另一个字节(有空闲空间) |
| 1   | valid | RX 缓冲区中有可读取的字节 |

所有其他位读出为 0。

### divisor (0x2,2 字节)

16 位波特率分频系数,可通过 `wmask[2]`(低字节)和 `wmask[3]`(高字节)按字节写入。一个自由运行的 16 位计数器每次到达零时用该分频系数重新装载;由此产生的节拍(`ce`)为 TX 和 RX 状态机提供时钟。因此在默认配置下,位时间等于 `divisor` 个内核时钟周期——具体取值取决于精确的期望速率,可设为 `clock_freq / baud_rate - 1` 或 `clock_freq / baud_rate`。

## 行为

- TX 和 RX 各有一个单入口的 1 字节保持缓冲区(`CrossBuffer`):它每次只能保存一个字节,且只有在为空时才能写入字节、为满时才能读出字节。
- 缓冲区与 TX/RX 移位逻辑之间的传输发生在波特率节拍(`ce`)上,因此缓冲区的每一侧都按各自时钟域的节奏运行——CPU 侧连续运行,串行侧每个位周期一个节拍。
- RX 输入通过两级移位寄存器进行同步;在起始位的下降沿检测到空闲状态,然后以 LSB 在前的方式移入 8 个数据位。
- 读请求(`reqValid && !wen`)仅在地址偏移为 0 时才会弹出 RX 缓冲区。
- `respValid` 在 `reqValid` 之后的一个周期被置起——每次读和写都以延迟一个周期的响应完成。
