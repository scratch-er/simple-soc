# GPIO

32 位通用并行 I/O 外设。实现在 `src/main/scala/gpio/Gpio.scala` 中。

## 寄存器映射

外设内部的寄存器偏移（地址的第 2 位选择寄存器，其余地址位被忽略）：

| 偏移 | 大小 | 寄存器 | 描述 |
|------|------|--------|------|
| 0x0  | 4    | output | 输出数据寄存器 |
| 0x4  | 4    | input  | 输入数据寄存器（只读） |

## 寄存器

### output (0x0)

32 位输出锁存器，复位值为 0。通过写选通信号按字节写入：每个 `wmask[n]` 位更新 `wdata[8n+7:8n]`。持续驱动 `pins.output` 引脚。

### input (0x4)

`pins.input` 引脚的 32 位快照，通过一个 2 级移位寄存器进行同步。写入无效。

## 行为

- 仅当 `addr[2] === 0`（选中 output）时写操作才会提交；input 寄存器无法被写入。
- 读操作在 `addr[2] === 0` 时返回 output 寄存器，否则返回 input 寄存器。
- `respValid` 在 `reqValid` 之后的一个周期置位，因此每次访问在下一周期完成。
