# 定时器

16 位双级定时器，带有 4 路 PWM 比较通道。实现在 `src/main/scala/timer/Timer.scala` 中。

## 概述

定时器由预分频级（`cnt0`/`wrap0`）和计数级（`cnt1`/`wrap1`）组成：

- `cnt0` 每个核心时钟周期加 1，达到 `wrap0` 时回绕为 0，即每 `wrap0 + 1` 个周期产生一次节拍。
- `cnt1` 在每次 `cnt0` 回绕时加 1，达到 `wrap1` 时回绕为 0。

计数器（`cnt1`）持续与 4 个比较寄存器进行比较；每次比较的结果驱动一路 PWM 输出引脚。

## 寄存器映射

外设内部的寄存器偏移：

| 偏移 | 大小 | 寄存器 | 描述 |
|------|------|--------|------|
| 0x0  | 2    | cnt0   | 预分频计数器 |
| 0x2  | 2    | cnt1   | 计数器 |
| 0x4  | 2    | wrap0  | 预分频回绕值 |
| 0x6  | 2    | wrap1  | 计数器回绕值 |
| 0x8  | 2    | cmp0   | PWM 0 的比较值 |
| 0xA  | 2    | cmp1   | PWM 1 的比较值 |
| 0xC  | 2    | cmp2   | PWM 2 的比较值 |
| 0xE  | 2    | cmp3   | PWM 3 的比较值 |

## 寄存器

### cnt0 / cnt1 (0x0 / 0x2)

计数级寄存器，复位值均为 0。每级每个时钟加 1（cnt1 仅在 cnt0 回绕时加 1），当计数值等于其回绕寄存器时回绕为 0。写入会直接载入寄存器，因此软件可以初始化或复位计数器。由于读取两个寄存器之间 cnt0 可能回绕，应成对读取计数器，若 `cnt1` 发生变化则重试。

### wrap0 / wrap1 (0x4 / 0x6)

cnt0 和 cnt1 的回绕值，复位值均为 0xffff。当计数值等于回绕值时，该级回绕为 0，因此每级共有 `wrap + 1` 个不同的计数值（0 到 wrap）。

### cmp0 – cmp3 (0x8 – 0xE)

4 路 PWM 通道的比较值，复位值均为 0。

## 行为

- 所有寄存器读回上次写入的值（cnt0/cnt1 则为实时计数值）；读取没有附带效应。
- 每路 PWM 输出都经过寄存器打拍：`pwmN` 为 `cnt1 < cmpN` 延迟一个周期的结果。
- `respValid` 在 `reqValid` 之后的一个周期置位，因此每次访问在下一周期完成。

## 引脚

| 引脚 | 方向   | 描述 |
|------|--------|------|
| pwm0 | 输出   | PWM 输出 0，`cnt1 < cmp0`（已打拍） |
| pwm1 | 输出   | PWM 输出 1，`cnt1 < cmp1`（已打拍） |
| pwm2 | 输出   | PWM 输出 2，`cnt1 < cmp2`（已打拍） |
| pwm3 | 输出   | PWM 输出 3，`cnt1 < cmp3`（已打拍） |
